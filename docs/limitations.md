# Ограничения и следующие шаги

- Нативные установщики, системное хранилище, Minecraft и обновления необходимо проверять на целевых ОС. Linux-сборка и браузерные тесты этого не доказывают.
- Для Minecraft требуется официальная лицензия и доступ к Microsoft/Xbox/Minecraft Services. Поддержка Microsoft-входа зависит от политики Microsoft и используемой регистрации приложения; ошибки разрешений нельзя исправить обходом проверки лицензии.
- Vanilla-профили реализуются первыми. Fabric и Forge, импорт модпаков и синхронизация игровых миров требуют отдельной реализации и тестирования.
- Скины личного кабинета Auralis не меняют официальный скин Minecraft. Плащи предусмотрены в модели данных; покупка/выдача плащей и их отображение в игре не реализованы.
- Встроенного платёжного сервиса нет. API не выдаёт лицензии Minecraft.
- Без сертификата Windows приложение может вызывать SmartScreen. Без Developer ID и Apple notarization macOS выдаёт предупреждение Gatekeeper. Подписанные публичные выпуски требуют учётных записей разработчика и настроенных секретов CI.
- Значение Lighthouse >90 и соответствие WCAG AA целиком не подтверждены автоматически. Нужны отдельный аудит готового сайта, ручная проверка клавиатуры, контраста, озвучивания и прогон на мобильных устройствах.
- Юридическая доступность названия Auralis не проверялась.
- Перед публичной эксплуатацией нужны мониторинг, политика хранения/удаления персональных данных, ротация ключей, почтовая репутация, нагрузочные испытания и проверка восстановления бэкапов.
