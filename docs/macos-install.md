# Открытие Auralis на Mac

Скачайте DMG для Apple Silicon из официального релиза ndzeone/Auralis, откройте образ и перенесите Auralis в «Программы». ARM64-сборка предназначена для M1 и новее; для Intel она не подходит.

Начиная с 0.1.3 CI подписывает сборку локальной ad-hoc подписью, если Developer ID не настроен. Перед публикацией проверяются целостность подписи, запуск настоящего .app и IPC. Это не нотариализация Apple: macOS всё ещё может блокировать приложение, полученное из интернета.

Если написано «разработчик не проверен», попробуйте открыть приложение один раз, затем перейдите в «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».

Если написано «приложение повреждено» и кнопки нет, сначала скачайте новую версию и замените старую копию в «Программах». Только для собственной доверенной копии этого проекта можно снять карантин с одного приложения в Терминале:

```sh
codesign --verify --deep --strict --verbose=2 /Applications/Auralis.app
xattr -dr com.apple.quarantine /Applications/Auralis.app
open /Applications/Auralis.app
```

Если первая команда сообщает об ошибке подписи, остановитесь и скачайте приложение заново; не обходите ошибку целостности. Команда xattr снимает карантин только с Auralis и не превращает локальную подпись в подпись Apple. Отключать Gatekeeper для всей системы не требуется.

Для распространения без этих ручных действий нужны платный Apple Developer ID, сертификат Developer ID Application и успешная нотариализация. В GitHub Secrets настраиваются MAC_CSC_LINK, MAC_CSC_KEY_PASSWORD, APPLE_ID, APPLE_APP_SPECIFIC_PASSWORD и APPLE_TEAM_ID; значения секретов не передаются в чат. Production-сборка сохраняет hardened runtime и использует отдельные entitlements без исключения library validation.
